Glossário

Termos técnicos explicados em linguagem simples. Filtre por área ou use a busca no topo.

TI
API

Conjunto de regras que permite que dois sistemas troquem informações entre si.

TI
Nuvem (Cloud)

Servidores acessados pela internet, usados para guardar dados e rodar programas sem instalar nada localmente.

TI
Banco de dados

Sistema organizado para guardar, buscar e atualizar informações de forma estruturada.

Indústria
Automação

Uso de máquinas e sistemas para executar tarefas antes feitas manualmente, com menos intervenção humana.

Indústria
Manutenção preditiva

Uso de dados de sensores para prever falhas em equipamentos antes que elas aconteçam.

Saúde
Prontuário eletrônico

Versão digital do histórico médico do paciente, acessível pela equipe de saúde de forma segura.

Saúde
Telemedicina

Atendimento médico realizado à distância, por vídeo ou mensagem, usando a internet.

Educação
Ensino híbrido

Modelo que combina aulas presenciais e atividades online no mesmo curso.

Educação
Acessibilidade

Conjunto de práticas que garantem que qualquer pessoa consiga usar e entender um conteúdo, produto ou espaço.
